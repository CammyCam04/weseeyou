This web applicaion will have Python and FastAPI for the backend and React + TypeScript for the Frontend. Right now, I'm not worrying about storing the data just yet, but when that time comes, it will be on a PostgreSQL server on AWS RDS. This application is going to be used to find all current politicans currently in office and canidates running across the country. A user will be able to view their profile to find key facts about them to make it easier to learn about their canidates. Ideally, it would be stances, affiliations, contriversies, political leaning, etc,. This would be accomplished via the form of the API calls and Webscraping.

### Option 1: The Official FEC API (OpenFEC) — Recommended for Stability

  The Federal Election Commission provides a free, official developer API (OpenFEC) which is the most stable and
  accurate source of federal campaign finance data.

  • Website: https://api.open.fec.gov
  • What it does: Provides real-time financial totals, spending, and contributions directly from official filings.
  • The Catch: The FEC provides raw filing data; it does not automatically group contributions into neat industry
  sectors (like "Securities & Investment" vs "Lawyers") like OpenSecrets did. To get those categories, you would have
  to write custom aggregation logic mapping contributor employers/PAC categories.
  ──────
  ### Option 2: Scraping OpenSecrets' Web Profiles — Best for Industry Sectors

  If you want the exact industry-categorized donor lists and percentages we just built in the UI, you can write a
  python scraper inside congress_service.py.

  • How it works: OpenSecrets hosts a public profile webpage for every politician showing their top donor industries
  (e.g.,  https://www.opensecrets.org/members-of-congress/summary?cid=N00007836 ).
  • The Advantage: The  @unitedstates  dataset we are using already contains the official OpenSecrets candidate ID (e.
  g.  opensecrets: N00007836 ) for every politician. Our python service can scrape their public HTML table, extract
  the sector names/contributions, and cache them. This keeps the data 100% free and structured exactly as you want it.
  ──────
  ### Option 3: OpenSecrets Bulk Data Downloads — Best for Offline Database

  While their live query API is gone, OpenSecrets still publishes free bulk data dumps (CSV/SQL database files) for
  researchers and developers.

  • How it works: You download the bulk ZIP files, load them into your PostgreSQL database, and index the tables.
  • The Advantage: Highly performant, completely offline, and contains all historical categorization rules.
  ──────
  ### Option 4: FollowTheMoney.org API — Best for State-Level Coverage

  • Website: FollowTheMoney.org https://www.followthemoney.org/
  • What it does: Aggregates political donations at both the federal and state level (e.g. state senators, governors,
  etc.).
